# Amazon creator fields

- `amazon_storefront_url` — Amazon storefront/profile URL
- `amazon_video_url` — Amazon Live or shoppable-video URL
- `amazon_discovery_source` — e.g. Explore related content
- `amazon_reviewed_survival_tabs` — published Survival Tabs review flag
- `amazon_shoppable_video` — Amazon Live/shoppable-video creator flag
- `amazon_fit_score` — internal 0–100 fit score
- `amazon_content_analysis` — hook/demo/reaction/claims/CTA/repeatable-format notes
