# Creator CRM — KISS workflow

The Creator Partnerships page must optimize for daily outreach, not database completeness.

## Primary one-page workflow

1. Not contacted
2. Contacted / waiting
3. Follow up
4. Responded
5. Sample

Each step is a collapsible section on the same page. Creator rows stay compact. Expand a creator only when more detail is needed.

## Important information first

Show in the compact row:
- creator name
- follower count / reach
- YouTube link
- email / contact link
- days since contact
- response state
- sample state
- next follow-up

Hide secondary research fields behind the creator expansion.

## Remove from primary workflow
- owner labels when the owner is already obvious
- Perry approval / Perry queues
- priority labels such as High/Medium/Low when follower count is more useful
- long explanatory page copy
- duplicate Knowledge Center and Content navigation (those live in the separate tabs-content Lovable app)

## Interaction principle

KISS: few clicks, obvious next action, spreadsheet-like scanability.
